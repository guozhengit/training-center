## 2. 工作区模型（务必先理解）

应用启动时必须定位到**工作区根**，判定规则（`WorkspaceLocator`）是**单根双条件**：

```
config/ 是目录                                    AND
output/coding-ai-exam/catalog/questions.json 是普通文件
```

- 设了 `TRAINING_WORKSPACE` → 直接用该路径，不满足条件就启动失败；
- 没设 → 从 `user.dir` 逐级向上回溯，命中即停。

当前工作区根就是 **`D:\AI-SOURCE\training-center`**（`output/` 已并入项目内，不再有独立上级目录）。

工作区布局：

```
training-center/
├── config/                     只读：题索引
├── starters/                   只读：代码骨架
├── output/coding-ai-exam/      只读：题库
├── output/interview/           只读：面试资料
└── output/training-runtime/    可写：database / sandboxes / exports / logs
```

SQLite 库文件：`output/training-runtime/database/training.db`（Flyway 自动迁移）。

## 4. 启动后端（8080）

```powershell
$env:TRAINING_WORKSPACE = "D:\AI-SOURCE\training-center"
cd D:\AI-SOURCE\training-center

# 构建（约 40s；Maven 必须联网走阿里云镜像，不能加 -o）
& "D:\Program Files (x86)\apache-maven-3.9.9\bin\mvn.cmd" -B -f pom.xml `
    -s deploy\maven\settings.xml -DskipTests package

# 启动（与生产一致的 jar 方式）
& "D:\jdk\jdk-17.0.12\bin\java.exe" `
    -jar training-web\target\training-web-1.0.0-SNAPSHOT.jar --server.port=8080
```

**`--server.port=8080` 不能省**：环境里注入了 `SERVER__PORT`（双下划线，实测 56687），Spring Boot 宽松绑定会把它映射成 `server.port`，而该端口被其它进程占用 → 不加参数就报 `Port 56687 was already in use`。命令行参数优先级最高，可覆盖。

启动日志关键行（看到即成功）：

```
Started TrainingWebApplication in 10.x seconds
Flyway: Database: jdbc:sqlite:.../training.db (SQLite 3.47)
Successfully validated 3 migrations
```

## 5. 启动前端（5173）

```powershell
cd D:\AI-SOURCE\training-center\training-ui
npm run dev
```

vite 已配代理：`/api` → `http://localhost:8080`，所以**访问 http://localhost:5173/ ** 就同时拿到前端与接口（直接打 8080 是后端静态资源版，也能用）。

改前端代码无需重启（HMR）；**只有改了后端才要重启 java 进程**。

## 8. 前端开发注意事项（踩过坑）

- **父传子 prop 必须显式 `.value`**：只有 setup 顶层返回的 ref 才自动解包；`props.xxx`（普通对象）里的 ref **不解包**。写 `:p="obj.ref"` 会把 Ref 对象传下去，子组件 `v-for` 迭代 Ref 直接抛错 → **整页白屏**。例：`:session-form="training.sessionForm.value"`。
- **改完 UI 必须用真实浏览器验证**，编译 200 / HMR 正常只能排除语法错。可用：
  `chrome.exe --headless=new --disable-gpu --no-sandbox --virtual-time-budget=8000 --dump-dom URL`
- flex 单行省略号必须 `min-width:0` + `overflow:hidden` 成对出现，否则布局被文字撑乱。

## 9. 停止与重建

```powershell
# 1) 先停后端（Windows 下 jar 被占用会导致 mvn clean 失败）
$c = Get-NetTCPConnection -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue
if ($c) { Stop-Process -Id $c[0].OwningProcess -Force }

# 2) 后端重新打包
$env:JAVA_HOME = 'D:\jdk\jdk-17.0.12'
mvn -B -f pom.xml -s deploy/maven/settings.xml -DskipTests clean package

# 3) 前端重新构建
cd training-ui && npm run build
```

## 10. 常见故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `Port 56687 was already in use` | 环境变量 `SERVER__PORT` 被宽松绑定 | 启动加 `--server.port=8080` |
| `Port 8080 was already in use` | 遗留 java 进程占用 | 按第 9 节先杀进程 |
| `mvn clean` 删不动 jar | Windows 文件锁 | 停掉运行中的 java 进程 |
| `Cannot locate workspace root` | 工作区根不满足双条件 | 显式设置 `TRAINING_WORKSPACE` |
| curl 本地接口报 502 | 走了系统代理 | 加 `--noproxy '*'` |
| 页面白屏 | 多半是 ref 未 `.value` 传给子组件 | 见第 8 节 |
| 图标/动画 404 | `dist/algo-anim` 未更新 | 重新 `npm run build` |

## 11. 判题链路（了解即可）

```
前端「运行/提交」
  → POST /api/training/attempts/{id}/run     (dry-run：不改状态、不排复习)
  → POST /api/training/attempts/{id}/judge   (正式判题)
      → JudgeService → MavenJudgeRunner: mvn -o -q -Dtest=X test
      → SurefireReportParser 解析 target/surefire-reports/TEST-*.xml
      → 返回用例级结果 (name/status/durationMs/expected/actual)
```

「随机抽题」不需要专门接口：`POST /api/training/sessions` **不传 `questionIds`** 即走 `QuestionSelector` 随机选题（`seed` 默认 `System.nanoTime()`）。
